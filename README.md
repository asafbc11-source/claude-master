# קלוד מאסטר 🎓

קורס אינטראקטיבי מקיף בעברית — מאפס מוחלט ועד רמת מומחה בכל יכולות קלוד.
מבוסס על הדוקומנטציה הרשמית של Anthropic, מאמרי ההנדסה שלה, מדריכי המשתמשים המתקדמים
ומקורות מקצועיים נוספים. נכון לאוגוסט 2026.

### מבנה הקורס

**📘 מסלול הליבה (1–10)** — מאפס: מה זה AI, Claude.ai, הנדסת פרומפטים,
Claude Code מההתקנה ועד פרויקטים, Cowork, Skills, MCP וחיבורים, API, והתמונה הגדולה.

**⚡ מסלול המאסטר (11–16)** — הנדסת הקשר · Claude Code ברמת מומחה · ריבוי סוכנים
ומקביליות · ארכיטקטורת סוכנים · מהחזית (חוקרים ומומחים) · ארגז הכלים הסודי.

**🏁 סיום (17)** — פרויקט הגמר: מוצר אמיתי מקצה לקצה.

### יכולות האפליקציה

- 🔊 **מורה קולי** בכל שיעור — הקראה בעברית, שליטה במהירות, מעבר בין משפטים
- 🎬 **הדגמות אינטראקטיביות** — טרמינל שמקליד לבד, סימולציות צ'אט, תרשימים מונפשים והשוואות
- 🛠️ **תרגילים אמיתיים** לביצוע בקלוד, עם קריטריוני הצלחה לסימון עצמי
- 🧠 **בחנים חכמים** — שאלות אקראיות ללא חזרות עד מיצוי המאגר
- 🎯 **תרגול מעורב** מכל המודולים
- 🔍 **חיפוש** בכל תוכן הקורס
- 🏆 **הישגים, נקודות ורצף ימים**
- 🔧 **מדריך הפעלה לכל כלי** — מה צריך מראש, שלבי ההתקנה, איך יודעים שהצליח, ומה עושים כשלא
- ⚙️ **הסבר "איך זה עובד"** לכל כלי — המנגנון מאחורי הקלעים, לא רק ההוראות
- ✨ **כפתור "פתח את זה בקלוד"** בכל דוגמת פרומפט — עובר לשיחה עם הטקסט מוכן, בחינם
- 🎓 **מורה מובנה שעונה מיד** — מנוע שנבנה במיוחד לאפליקציה: מבין את השאלה, מחפש ב-1,200 קטעי תוכן ומרכיב תשובה. בלי שרת, בלי מפתח, בלי אינטרנט
- 📱 **זיהוי מכשיר** — ההוראות מותאמות למערכת ההפעלה שלך
- 💰 **סימון עלויות** — כל מודול מסומן ✅ כלול במנוי או 💳 דורש תשלום נפרד, עם מתג להסתרת מה שעולה כסף
- 🌓 מצב כהה ובהיר · עברית RTL מלאה · תחושת אפליקציה נייטיבית
- 🔒 כל ההתקדמות נשמרת במכשיר בלבד (localStorage). שום מידע לא נשלח לשום מקום.

## איך משתמשים — עכשיו

לחיצה כפולה על `index.html` פותחת את האפליקציה בדפדפן. זהו.

## התקנה בטלפון כאפליקציה (PWA)

דפדפנים מאפשרים התקנה רק מכתובת אינטרנט. הדרך החינמית היא **GitHub Pages** —
וזה בדיוק אחד התרגילים בקורס (מודול 5, "האתר שלך עולה לאוויר"):

1. פתחו חשבון חינמי ב-github.com
2. פתחו טרמינל בתיקייה הזו, הקלידו `claude`, ובקשו:
   *"העלה את התיקייה הזו ל-GitHub ופרסם אותה כאתר חי ב-GitHub Pages"*
3. פתחו את הכתובת שקיבלתם בטלפון:
   - **אנדרואיד (Chrome):** תפריט ⋮ ← "התקנת אפליקציה"
   - **אייפון (Safari):** כפתור שיתוף ← "הוסף למסך הבית"
4. מרגע ההתקנה האפליקציה עובדת גם בלי אינטרנט.

## על המורה הקולי

ההקראה מופקת על ידי מנוע הדיבור המובנה של המכשיר — לא הקלטה של קריין אנושי.
האיכות משתנה בין מכשירים: באנדרואיד ובאייפון היא בדרך כלל טובה, ב-Windows פחות.
הכול קורה במכשיר, בלי אינטרנט ובלי עלות.

## מבנה הקבצים

```
claude-learning-app/
├── index.html          ← האפליקציה כולה (קובץ יחיד, עצמאי, ~600KB)
├── manifest.json       ← הגדרות PWA
├── sw.js               ← Service Worker (עבודה אופליין)
├── icon-192.png        ← אייקון
├── icon-512.png        ← אייקון גדול
└── src/                ← מקורות לעריכה עתידית
    ├── shell.html      ← עיצוב + מנוע האפליקציה
    ├── content/        ← תוכן: m01–m17, deepening, howto, pricing, glossary
    ├── tutor.js        ← מנוע המורה המובנה (חיפוש והרכבת תשובות)
    ├── build.py        ← מרכיב הכול ל-index.html
    ├── serve.py        ← שרת מקומי לבדיקות
    └── make_icons.ps1  ← יצירת האייקונים
```

## עדכון תוכן

עורכים קובץ ב-`src/content/`, ואז:

```bash
python src/build.py
```

(או פשוט מבקשים מ-Claude Code לעשות את זה 😉)

הוספת `--debug` מייצרת גם גרסת פיתוח שטוענת את הקבצים בנפרד — נוח לאיתור תקלות.
